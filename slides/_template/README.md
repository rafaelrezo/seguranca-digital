# Template de apresentação

- Fonte colaborativa legível no Google Apresentações: https://docs.google.com/presentation/d/1eQAii3CdA-cv1bdwiNAYvAlb7FhPxhRcYbCv976i0PQ
- Snapshot versionável: `fonte/template-seguranca-digital.pptx`
- Exportação para uso: `exportados/template-seguranca-digital.pdf`

## Uso

1. Faça uma cópia do arquivo nativo.
2. Renomeie com `Axx — título da aula`.
3. Use os layouts por função narrativa, não como sequência rígida.
4. Remova slides não utilizados e conteúdo de exemplo.
5. Revise notas, fontes, contraste, legibilidade e checkpoints ativos.
6. Exporte PDF e PPTX para a pasta da aula.

O template oferece capa, cenário, evidência, conceito, comparação, decisão, demonstração, ponte para a prática, síntese e referências.

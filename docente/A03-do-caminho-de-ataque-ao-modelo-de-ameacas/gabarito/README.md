# Gabarito docente — A03

Aceitar múltiplos modelos quando fluxos, fronteiras, suposições e consequências estiverem explícitos. Um caminho plausível de referência é: identidade remota comprometida → VPN → servidor de arquivos → estação de engenharia → jump host OT. Isso é hipótese, não conclusão dos logs.

Controles possíveis: identidade individual e MFA; privilégio mínimo; segmentação e jump host; bloqueio de fluxo direto; allowlisting; backup testado; logs correlacionados; plano de acesso emergencial. Exigir validação de segurança e continuidade operacional.

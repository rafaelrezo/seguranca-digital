# Template de atividade prática

- Fonte colaborativa legível no Google Docs: https://docs.google.com/document/d/1cIm9sboZ9mQY0_wNte8wn20sacZadUviEZbrZxbKBes
- Snapshot versionável: `fonte/template-atividade-pratica.docx`
- PDF do Classroom: `pdf/template-atividade-pratica.pdf`

## Uso

1. Faça uma cópia do arquivo nativo.
2. Preencha missão, objetivos, ambiente, etapas, evidências e rubrica.
3. Remova instruções de autoria e qualquer solução da versão do estudante.
4. Teste a prática do zero e revise tempos e resultados.
5. Exporte DOCX e PDF para a pasta da aula.

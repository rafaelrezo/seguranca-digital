# A12 — Proteção de dados: segundo encontro

O docente confirmou dois encontros completos de proteção de dados, A11 e A12. O [material de estudo de proteção de dados](A11-protecao-de-dados.md) reúne classificação, circulação, LGPD, permissões, DLP e recuperação. Ele pode ser consultado para rever os conceitos e exemplos do bloco; a página publicada não registra quais seções foram tratadas em cada encontro nem comprova a execução de cada demonstração.

Para a continuidade, retenha a pergunta: **que ações um processo executado com acesso legítimo pode realizar sobre um dado legível?** A [A13 — proteção de endpoints](A13-protecao-de-endpoints.md) examina execução, alcance, rastros e resposta.

O [parecer integrado](../atividades/A11-A12-parecer.html#atividade) reúne dados e endpoint em uma única entrega após A13. O endereço preserva a identificação anterior; o enunciado mostra a sequência atual A11–A13.

## Atividade {#atividade}

Use o [parecer integrado](../atividades/A11-A12-parecer.html#atividade) para rever os insumos de dados. Complete a parte de endpoint depois da A13; não há uma entrega separada para este encontro.
